# Prompt 1: HTML/CSS/JavaScript Design

Design a complete 5-page supercar buying and selling website using HTML, CSS, and JavaScript. The website should look modern, trustworthy, premium, and fully responsive.

Use the attached sample file as inspiration. Take inspiration from its layout, typography, spacing, and overall user experience while creating an original design that fits an automotive brand.

Business Details:
- Business name: Flash Cars
- What we do: Buy and sell new and used super car vehicles
- Target audience: Super car buyers and sellers
- Main goal: Generate leads, showcase inventory, and encourage inquiries
- SEO keywords: Supercars, ferrari, lamborghini

Build These 5 Pages:
- Home: Hero with search or CTA, featured vehicles, trust indicators, why choose us, testimonials, and final CTA
- About: Company story, mission, values, and what sets us apart
- Inventory: Responsive grid of vehicle listings with Unsplash placeholder images, filters (make, model, price, year), and inquiry buttons
- Sell Your Car: Explain the selling process, benefits, valuation form, FAQs, and CTA
- Contact: Contact form, dealership information, map placeholder, business hours, and social links

Requirements:
- Sticky header with logo, navigation, CTA button, and mobile menu
- Footer with quick links, contact details, and social media
- High-quality automotive imagery using Unsplash placeholders
- Modern UI with subtle animations and hover effects
- Fully mobile responsive
- SEO-ready with semantic HTML, proper headings, meta tags, and descriptive alt text
- Ensure all buttons, forms, and navigation are functional
- Build everything as a single previewable artifact with clean, organized code

# Prompt 2: WordPress Conversion

Convert this design into a WordPress website using Elementor. Use native Elementor widgets wherever possible and build layouts with Containers instead of Inner Sections. The Atomic Editor is disabled, so do not use Atomic Elements. The Novamira plugin is installed to help you understand and structure Elementor elements more effectively.

Create a new WordPress menu for all pages created as part of this design and set the appropriate page as the homepage.

For the header and footer, use XPRO to build custom templates with Elementor. Do not use Elementor Pro widgets. Save both the header and footer templates to the XPRO library so they can be easily customized later.

Use WPForms for all contact and inquiry forms on the site. Use novamira to help you.

Once the conversion is complete, publish the website to the connected WordPress site.
