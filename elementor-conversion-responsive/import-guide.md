# Import Guide

1. Create the five WordPress pages: Home, About, Inventory, Sell Your Car, Contact.
2. Import the matching JSON from pages/ into Elementor. The structures use Containers and editable native widgets.
3. Configure responsive values for desktop/tablet/mobile as included in the JSON.
4. Create the WPForms forms described in forms/wpforms-map.json and replace each shortcode/widget placeholder after import.
5. Import xpro/site-header.json and xpro/site-footer.json into the XPRO Library, then assign them as the site header/footer using XPRO.
6. Create a new WordPress menu containing Home, About, Inventory, Sell Your Car, and Contact. Set Home as the site homepage.
7. Replace remote image URLs with media-library images after upload.
8. Verify typography, spacing, links, forms, header navigation, and breakpoint behavior in Elementor before publishing.

Notes:
- The JSON files are editable Elementor-style structures intended for manual import/reconstruction.
- Exact XPRO metadata can vary by installed XPRO version, so save/assign the imported header/footer through XPRO.
- Form IDs are placeholders; use the IDs generated by WPForms in the target WordPress site.
