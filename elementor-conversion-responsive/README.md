# Flash Cars — Responsive Elementor Conversion

Responsive Elementor conversion package for the Flash Cars HTML source.

Implementation rules:
- Elementor Containers only; no Inner Sections.
- Native Elementor widgets wherever possible.
- Atomic Editor disabled; no Atomic Elements.
- No Elementor Pro widgets.
- WPForms placeholders are mapped separately.
- XPRO header/footer templates are provided separately.
- Responsive intent is explicit for desktop, tablet, and mobile.
- Original elementor-conversion folder is preserved unchanged.

Manual import/deployment is documented in import-guide.md.
